# Identidad de Matangazo

Regla del usuario: conservar los tonos originales de rojo y azul. No sustituirlos por coral, otros azules o una dirección visual negra.

- Azul de marca: `#1427DF` (RGB 20, 39, 223).
- Rojo de marca: `#E20613` (RGB 226, 6, 19).
- Fuente: colores planos dominantes del archivo original `C:/dev/matangazo publicidad/logos/logos/matangazo-logo-horizontal.png`. El azul también aparece en la web de Matangazo.
- Blanco como base. Azul profundo `#282E64` como apoyo para lectura y extremo del degradado existente de matangazo.mx.
- Se permite un tercer color que armonice con los dos principales. Esta versión usa amarillo cálido `#EABE12` como acento minoritario; nunca sustituye el rojo o el azul.
- Los tonos claros se obtienen mezclando los colores de marca con blanco. Mantener bloques de color y fondos difuminados, respetando legibilidad y rendimiento.
- Usar las variables de marca de `dist/styles.css`. No recolorear los archivos del logotipo ni introducir nuevos colores de identidad sin una indicación del usuario.
